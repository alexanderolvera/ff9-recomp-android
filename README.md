# FF9Recomp

FINAL FANTASY IX (Steam) with Memoria and Moguri Mod, running natively on Android (AYN Thor)
without Unity: the game's own .NET assemblies run on .NET 8 Mono, over an engine written here.

Contains no game code or data. See [docs/ROADMAP.md](docs/ROADMAP.md) and [docs/SPIKE.md](docs/SPIKE.md).
